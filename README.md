# 📊 Sentiment-Dashboard — Text Sentiment Analysis Dashboard

> An interactive web dashboard for real-time text sentiment analysis and NLP data visualization built with **Django**.

---

## 📌 Features
- **Real-Time Sentiment Analyzer**: Classifies user inputs into Positive, Neutral, and Negative sentiments.
- **Analytical Charts**: Visual distribution charts and historical trend analytics.
- **Admin Management**: Django Admin panel for dataset monitoring and feedback logging.

---

## 🛠️ Tech Stack
- **Framework**: Django (Python 3.x)
- **NLP & Data Processing**: NLTK, Scikit-Learn, Pandas
- **Frontend**: Bootstrap / Chart.js

---

## 🚀 Getting Started

```bash
git clone https://github.com/MasterPandaa/Sentiment-Dashboard.git
cd Sentiment-Dashboard
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
Visit [http://127.0.0.1:8000](http://127.0.0.1:8000) to access the dashboard.
